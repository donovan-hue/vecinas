      Cómo lee Vecinas

      01

      Recibe el código

      Un repositorio de GitHub, una carpeta o un archivo pegado. Nada se ejecuta y nada se instala: el código se trata como texto.

      02

      Mide la estructura

      Cuenta líneas, funciones, clases, anidamiento y caminos posibles (complejidad). Es el equivalente a una radiografía: forma sin juicio.

      03

      Teje las dependencias

      Resuelve cada import a un archivo real y dibuja el grafo. Ahí aparecen ciclos, nodos centrales y código que nadie llama.

      04

      Anticipa el error

      Aplica reglas de riesgo (errores silenciados, inyección, secretos, comparaciones laxas) y pondera cada archivo por exposición.
